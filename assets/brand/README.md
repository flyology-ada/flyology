# Flyology artwork

The SVG files are the editable sources for the Flyology mark, horizontal
lockup, one-color mark, and refined variants board. The `previews/` directory
contains rendered PNGs, including 512, 128, and 32 pixel versions of the
primary icon.

Use `flyology-horizontal-lockup.svg` on light backgrounds and
`flyology-horizontal-lockup-dark.svg` on dark backgrounds. Use
`flyology-mark-transparent.svg` when only the mark is needed.
