Subject: [PATCH] ada: Remove stale validity raises from automatic lock-free bodies

An automatically selected lock-free protected body is analyzed before its
protected type is marked lock-free. The original statements can therefore
contain compiler-generated invalid-data validity raises. They remain when
the statements are copied into the generated lock-free body, although direct
analysis of an explicitly lock-free body suppresses those checks.

On x86-64 Linux, the added protected Duration round-trip test rejects a
valid negative value at -O0 -gnatVa and aborts in fold_convert_loc at
-O2 -gnatVa. Remove only generated CE_Invalid_Data raises while traversing
the copied statements. Source raise statements and other checks remain.

The test is an executable gnat.dg case with -O2 -gnatVa. It fails before
the patch and runs successfully afterward on x86-64 Linux. The standalone
patch applies with zero fuzz to the pinned GCC 13.2.0, 14.2.0, 15.3.0,
16.1.0, and 16.2.0 sources and to gcc-mirror/gcc master at
56de4652dbfc3a79ee4946f0274aba115bd83ccb (2026-09-22).

Published patchset CI exercises unpatched and patched Linux x86-64, Linux
AArch64, and macOS AArch64 compilers. Its GCC 16.2.0 x86-64 job records the
before/after behavior:
https://github.com/flyology-ada/gnat-patches/actions/runs/35117276018/job/104866768180

A direct unpatched Ubuntu GCC 13.3.0 x86-64 reproduction with
`gcc-13 -c -O2 -gnatVa protected_duration_validity.adb` also exits with status
1 and prints the complete GNAT bug box naming fold_convert_loc at
fold-const.cc:2505. The raw diagnostic and full `gcc-13 -v` output are retained
with the local submission package.

Testing still required for an upstream submission: bootstrap an otherwise
unmodified GCC tree with this patch alone, then compare the Ada and gnat.dg
testsuite results before and after. The published patchset CI builds with
--disable-bootstrap and contains other independent patches, so it does not

+--  { dg-do run }

+with Ada.Text_IO; use Ada.Text_IO;
+
+procedure Protected_Duration_Validity is
+   protected Control is
+      procedure Set (Value : Duration);
+      function Get return Duration;
+   private
+      Current : Duration := 0.0;
+   end Control;
+
+   protected body Control is
+      procedure Set (Value : Duration) is
+      begin
+         Current := Value;
+      end Set;
+
+      function Get return Duration is
+      begin
+         return Current;
+      end Get;
+   end Control;
+begin
+   Control.Set (-1.0);
+   if Control.Get /= -1.0 then
+      raise Program_Error with "protected Duration round trip failed";
+   end if;
+   Put_Line ("PASS protected Duration validity");
+end Protected_Duration_Validity;
